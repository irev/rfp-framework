# Architecture Decision Records

Use one file per consequential decision: `NNNN-short-title.md`. Keep decisions brief and link relevant requirement IDs.

## Template

```markdown
# ADR-NNNN: Title

Status: Proposed | Accepted | Superseded
Date: YYYY-MM-DD
Owners: ...
Related requirements: ...

## Context
What problem and constraints require a decision?

## Decision
What will we do, and within which boundary?

## Consequences
Benefits, costs, risks, migration and verification steps.

## Alternatives considered
Why were they not chosen?
```

See [ADR-0001](0001-core-vs-configuration.md) for the foundational boundary.
